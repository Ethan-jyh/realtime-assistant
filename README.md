# Realtime Assistant

Electron + React 实时语音助手源码，支持实时语音、独立深度回答、截图问答及可配置模型服务。

## 本地开发

```sh
npm ci
npm run dev
```

## 检查与构建

```sh
npm run typecheck
npm test
npm run build
```

模型与 ASR 凭据在应用设置中配置，不随源码分发。macOS 麦克风、系统音频及截图需相应系统授权。原生采集和打包目前以 macOS 为主。
