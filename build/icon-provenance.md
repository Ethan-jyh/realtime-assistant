# 图标素材来源

本轮最终采用企业微信，Spotify/QQ方案已撤回。

- icon.icns：逐字节复制本机 /Applications/企业微信.app/Contents/Resources/AppIconGov.icns（当前安装版本含教育版角标）。icon.png由该ICNS解码，仅用于开发模式。
- icon.svg：本机企业微信res/res.rcc中的wecom_colored_128.svg，原矢量参考。
- tray-wecom.svg：同RCC中的wecom_20.svg，原单色线条图形；生成的tray-wecom.png与tray-wecom@2x.png保留透明背景。
- 图标仅按用户要求用于该本机自用助手；菜单标题和系统应用名称仍为Realtime Assistant。
- 不读取或修改企业微信账号/消息数据，也不修改原企业微信应用。
