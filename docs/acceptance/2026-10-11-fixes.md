# 2026-10-11 修复与复测记录

本轮修复先前确认的问题，没有新增音频、ASR、录音、历史等后续模块。

## 修复内容

- IPC 通道常量独立于 Zod schema；sandbox preload 不再引用外部 zod，保留 sandbox/contextIsolation。
- 完整模型响应校验 choices/message/content/finish_reason；非法响应和非法端点返回错误事件，连接测试不把 interrupted 认作成功。
- 模型每次请求只进入一次终态，拒收完成后同批迟到内容；finally 取消 reader 并释放锁。
- vault 读入、解密或 JSON 结构失败时保留旧密文，新密钥仅留内存；UI 明确显示仅本次运行有效。
- 请求 started 事件使准备页和浮窗按 requestId 清空回答并过滤旧事件；取消显示停止接收，取消后可以重新提问。
- 公开模型配置原子落盘，重启恢复 Base URL/modelName；API Key 仍走独立 vault，不写入公开配置。
- 原窗口 E2E 等页面加载及实际显示后再断言，finally 始终关闭测试应用。
- 将已校验 SHA256 的官方同版本 Electron 运行程序装入 node_modules/electron，使默认测试无需临时 executablePath。
- 保留并纳入此前未提交的 main.tsx 双页面 hash 路由；它是两个窗口显示不同页面所必需的既有改动。

## 回归证据

环境：macOS 27.0.1 arm64，Node 24.11.1，Electron 44.7.0。

模型/vault 新增测试先在旧逻辑上得到 10 项断言失败，再修复到通过。真实窗口验证拆分前 window.api 为 undefined；依赖拆分后能发送模拟接口请求，但浮窗连续两问出现“回答一回答二”，随后补 started/requestId 处理并通过 GUI 回归。配置持久化与非法端点另有失败回归。

最终运行：

```bash
npm test
npm run typecheck
npm run build
npm run test:e2e -- --workers=1
git diff --check
```

结果：10 个测试文件、55 个单元测试通过；类型检查、构建和差异检查退出 0；2 个真实 Electron 端到端测试通过。GUI 回归覆盖桥接、保存并测试连接、连续两问、取消后再次提问、重启恢复模型配置、双窗口、失焦可见与尺寸切换。测试使用独立临时 userData 和本机 HTTP 模拟模型，没有真实凭据或付费请求。

未验证：用户实际模型供应商、真实 ASR、腾讯会议接收端排除。后续音频/ASR/录音/历史模块仍需按计划实现；这些结果不表示完整产品已完成。已有模板预置的默认模型仅为界面初始值，实际使用应填写自己的模型名。

运行工程：进入本工作树执行 npm run dev；首次安装仍需正常获取 Electron 依赖。node_modules 的本机运行程序不提交到 Git。
