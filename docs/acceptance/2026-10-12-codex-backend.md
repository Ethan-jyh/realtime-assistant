# 0.2.8 Codex后端与简约主题验收

设置新增回答后端选择API/Codex。Codex模型及官方思考强度从model/list读取；保存与页面重载保留，API配置与密钥不被清除。选择Codex不读取API密钥，不静默回退。

应用创建自己的harness会话，复用历史；session、模型或系统提示词变化时建立新会话并携带已确认上下文。流式事件按thread及turn归属过滤，预先到达的通知缓冲到请求响应后处理。取消结束旧进程，随后重连并只恢复自有会话。翻译使用独立客户端，避免和回答互相取消。

纯文字回答默认关闭常用命令工具，限定只读最小运行目录及工作区，审批拒绝；没有增加工具审批UI。模型思考强度原样传到turn/start.effort。截图类型可转成Codex图像输入，但本轮未发送真实截图。

主题改成中性灰黑、白色按钮，保留透明度、无阴影/无模糊、移动和穿透机制。
