# 0.2.7 界面精简验收

- 首页删除“设置并开始”、供应商标语、“自有 API”“本地保存”等说明。
- 三个场景入口均直接进入准备页；选择场景不触发采集，准备页底部保留明确的开始按钮。
- 准备页删除重复教程段落；保留个人资料、自定义提示词、资料导入、录音来源、思考模式及自动回答。
- 设置页删除说明和品牌标签；保留模型、语音识别、透明度、鼠标穿透及诊断日志控制。
- 浮窗删除重复启动说明，保留转录、连续回答卡片、问答、暂停恢复及保存。
- 石墨灰界面、低饱和绿主操作、统一表单和间距；无窗口阴影或背景模糊。

## 验证

类型检查与构建通过。161 项单元测试、35 项端到端测试通过（单 worker）。新增测试先验证旧首页失败，再验证三个精简入口均可进入、返回且会话仍为 idle。三个页面截图已人工检查，见 ui-0.2.7。

本次测试使用本机合成接口与隔离数据目录，未调用真实收费 API。用户退出后已覆盖同一路径的程序，安装版0.2.7核验通过：保留模型与ASR密钥、透明度0.87、鼠标穿透设置及已授予的屏幕录制权限；首页三个入口，单个可见窗口，最小化与恢复正常。
