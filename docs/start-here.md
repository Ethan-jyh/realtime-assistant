# 启动与使用

项目位置：`/Users/air/.codex/worktrees/realtime-assistant-plan/REA`。

日常使用：先激活旧助手并按 ⌘Q 完全退出，然后在 Finder 双击 `/Users/air/Documents/ChatGPT/REA/企业微信私有版.app`。这个独立程序直接加载本地界面，不会打开终端、不需要 Node 或 Vite。底部 Dock 图标现在显示。首用时按 macOS 提示允许所需的麦克风/系统音频录制权限；截图时另需屏幕录制。

原来的 `启动实时助手.command` 保留为源码构建入口，会打开终端；屏幕共享时请使用 `.app`。

开发调试时才使用：

```sh
cd /Users/air/.codex/worktrees/realtime-assistant-plan/REA
npm run dev
```

本机依赖已经安装。正式启动入口不会加载 `/private/tmp` 的诊断脚本。

X 会保存并完全退出，最小化会保留后台运行；更新版本时按 ⌘Q 完全退出旧实例，再双击 `.app`。首页点击“设置并开始”或选择模式，确认“录音设置”，然后点击右下角“▶ 开始实时转写”。个人资料可以不填。关闭音频时按钮显示“▶ 开始文字会话”，截图模式显示“▶ 开始截图问答”。未开始的浮窗也有“设置并开始”入口。纯文字会话中暂停录音和自动转写回答不可用；停止接收仅在生成时可用。录音模式可选择麦克风、系统音频或两者。开始会话后才会采集；结束会话会停止设备并保存历史。录音需要勾选“保存录音到本机”。只做文字问答可关闭“采集实时音频”。

API 配置里，“保存配置”独立保存，“保存并测试连接”另外执行真实请求。DeepSeek Base URL 为 `https://api.deepseek.com/v1`，本机验证模型为 `deepseek-flash`；阿里 ASR 为 `qwen-audio-3.1-asr-flash-streaming`，WebSocket 为 `wss://dashscope.aliyuncs.com/api-ws/v1/inference`。两项密钥已存到 macOS 加密存储，界面留空会保留原密钥。

API 配置 → 窗口设置：窗口不透明度 20%–100%（设置页与浮窗同步预览），拖动即保存并在重启恢复。⌘⇧O 显示/隐藏浮窗。

当前 `deepseek-flash` 对应 DeepSeek V4.1 Flash，支持图像输入，可以用于截图问答。合成截图通过真实 DeepSeek 视觉接口验证，系统截图到本机测试接口也通过；实际桌面向 DeepSeek 外发未测试。官方说明：https://api-docs.deepseek.com/guides/vision/ 。屏幕保护实际效果需要在你使用的腾讯会议共享方式和独立接收端核对。

[验证结果](acceptance/2026-10-11-core-runtime.md)

浮窗的“字号 − / 字号 +”位于内容操作区，旁边显示当前 px 数值；空白提示也会跟随字号变化。“收起 / 展开”只折叠窗口。“自动回答”只有音频会话启动后可用，纯文字和未开始状态会显示原因。

双方区分：在“录音设置”选择“我（麦克风）+ 对方（系统音频）”。左侧会显示不同标签与颜色；按来源区分，不是多人声纹识别。自动回答只针对系统音频发言。

自定义提示词：在准备页“个人信息”找到“自定义提示词”，填写后点击“保存提示词”；也会随开始会话保存。知识、资料、翻译和截图问答都会使用它。

回答已渲染 Markdown，标题、粗体、列表、代码和表格直接显示。暂停会释放采集音轨；点击“继续录音”会按原设备配置重建采集与 ASR，保留当前会话上下文；切换期间按钮显示“正在切换…”，失败会保留暂停状态并显示原因。

模型上下文：自动回答只由对方发言触发，但请求包含本次会话“我”和“对方”的全部已确认转写，带编号和来源标签；不再只发送最近一段记录。结束后在当前应用里继续追问也保留这段上下文，直到开始新的会话。

窗口流程：启动只显示选择/准备页。点击底部开始按钮并启动成功后，才显示辅助浮窗并隐藏准备页；浮窗的设置按钮切回准备页，当前会话继续运行，可点击“返回当前会话”回到浮窗。

拖动：窗口四周、边距和控件之间的空白区域可拖动移动；按钮、输入框、正文及滚动区域保留正常操作。

macOS 底部 Dock：本应用现在显示 Dock 图标。仍从启动入口打开；已创建浮窗后可用 ⌘⇧O 显示/隐藏。退出请在应用窗口激活时按 ⌘Q。

本次稳定性修复：自动回答等待对方发言稳定 2.5 秒，生成结束后保留至少 5 秒阅读间隔；新请求开始时保留上一条回答，首字到达再替换。生成失败或中断不会立即自动循环重试。

外放回音：麦克风明确请求系统回音消除和降噪；同时采集系统音频时，仅对高度匹配的回音副本做本地残余扣除。真实重复发言和不确定的同时发言优先保留。建议佩戴耳机，分路采集仍保持开启。

日志：API 配置页底部点击“打开日志目录”。固定目录为 `~/Library/Application Support/local-realtime-assistant/logs`，退出和重启后仍可查；故障时保留三个日志文件及发生时间。日志不包含密钥、对话或音频。

真实鼠标拖动与腾讯会议接收端黑影仍需现场复核；自动化已验证窗口坐标变化、禁用原生阴影与背景模糊。macOS 系统录屏提示组件不由本应用创建。

鼠标穿透：辅助浮窗默认穿透，按住 Option（⌥）时可点击和拖动，松开恢复穿透。准备/设置页不穿透。浮窗“穿透：开/关”、API 配置 → 窗口设置中的“鼠标穿透”或 ⌘⇧I 均可切换。要输入文字，先关闭穿透；按住 Option 打字可能输入特殊字符。按键检测异常时自动恢复可点击。

本次不透明度修复：此前设置页可见时只修改隐藏的浮窗，当前可见设置页仍保持 100%。现在当前设置页立即预览、浮窗同步变化、新创建窗口恢复保存值。
